Setlora is an **invoice-linked batch payment application** on **Portaldot V3 Testnet**. A payer can prepare up to 10 EVM-recipient invoices, check them, explicitly authorize test-token transfers, and inspect settlement evidence.

<Aside type="caution" title="Testnet software, not audited">
Setlora uses test pUSD. Do not send mainnet assets, real funds, wallet seed phrases, or private keys.
</Aside>

### Choose your path

- **New to Setlora?** Start with [Getting started](/docs/getting-started/).
- **Judging the hackathon?** Follow [How to test](/docs/how-to-test/) for a no-wallet walkthrough.
- **Sending a test payment?** Read [Send payments](/docs/send-payments/).
- **Holding a transaction hash?** Use [Verify a payment](/docs/verify-payment/) without connecting a wallet.
- **Unsure whether an account exists?** Try [Check a recipient](/docs/check-recipient/).
