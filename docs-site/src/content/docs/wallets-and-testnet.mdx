### Wallet safety

Setlora uses the wallet you explicitly connect. For financial actions, your wallet must authorize token approval and later confirm the batch settlement transaction. Never paste a seed phrase or private key into Setlora, GitHub issues, or a documentation form.

### EVM versus native addresses

- **EVM `0x...`:** supported by the current batch-payment form.
- **Native SS58 `5...`:** supported by the separate read-only account checker, **not** current EVM batch payouts.

Official test pUSD and testnet gas distribution may change. Setlora does not claim an unrestricted public faucet, and it does not automatically provision wallets or fund recipients.
